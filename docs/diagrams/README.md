## 그림 읽는 법

- **블록도 선:** 굵은 진한 빨강 = 전원, 가는 검정 = 신호, 파선 = PWM, 점선 = 무선. 그 밖의 선은 그림마다 범례에 있습니다.
- **상자:** 제목 탭이 붙은 회색 테두리 = 묶음(모듈·영역·단계), 점선 상자 = 대체 경로나 계획.
- **순서도 (ISO 5807):** 둥근 단말 = 시작·끝, 직사각형 = 처리, 마름모 = 판단, 평행사변형 = 입출력, 양옆 이중선 상자 = 미리 정의된 처리. 진한 빨강 선 = 중단·안전 경로.
- **상태도 (UML):** 둥근 사각형 = 상태, 채운 점 = 시작, 전이 라벨 = "사건 [가드] / 동작".
- **번호 주석:** 그림 속 ①, ② 같은 표시는 그림 아래 주석 표의 번호입니다.
- **수치 라벨:** M = 도구로 잰 값, F = 설계 파일 값, E = 추정, A = 가정.
